# 校异斋 · 多版本文本自动比对与人工校勘工具

面向古籍整理的多版本校勘工作台。一次载入 **3–5 个版本并指定底本**，自动按段落与句子对齐到同一组，组内逐版标出改动、新增、删减；人工挪动配对不串位，校记与来源始终跟着原句走。

## 核心工作流

1. **载入版本与定底本**：导入或粘贴 3–5 个版本（空行/换行分段，句末标点切句），点选其中一个为底本，其余勾选为参校，同屏对照。
2. **自动组对齐**：默认两级对齐——先按整段相似度对段，再在配对段内按句对句；某一版多/少整段时，后续段落不会错位。勾选「允许跨段落配对」时退化为整文本句级对齐。
3. **逐版标异文**：每个对齐组一行，底本在左、各参校一列；单元格独立判定 `改动 / 新增 / 删减 / 相同 / 疑错位`，改动处做**字符级增删高亮**（绿底=新增字，红删=删减字）。
4. **人工修正**：句子只在**本版列内**上移/下移配对，不能跨版拖拽，从结构上杜绝「版本串位」；可拆句、合并相邻组、锁定整组。
5. **校记随句走**：校勘说明与来源挂在「版本 + 句子」上，而不是对齐行上。换底本、增减版本、改规则重新对齐、重新分句都不丢；句子重切时按相似度自动迁移，无法归位的进入**失主校记**池，可手动指认。
6. **长文本分片**：DP 按底本行数分片让出主线程并显示进度，对照视图按底本句序分页（上一片/下一片），可处理上千句。
7. **导出**：
   - **多版本对照 HTML**：带颜色分类的逐组对照表，内嵌各版校记，可直接打印/存档；
   - **校勘记 Markdown**：按组列出底本、各参校异文类别、校记与来源；
   - **完整 JSON**：含正文、对齐组、人工锁定、校记、规则，便于备份与迁移。

## 多草稿与安全网

- 每个项目是一份独立草稿，存在浏览器 `localStorage`；可新建、切换、重命名、重开旧草稿。
- JSON 备份可在任意浏览器重新打开为新草稿，不覆盖当前工作。
- 最多保留 50 步撤销/重做（`Ctrl/⌘+Z`、`Ctrl/⌘+Shift+Z`），版本、规则、对齐、校记都可回退。
- 快捷键：`Alt+↓` 跳到下一处未接受差异；单元格可逐条接受，也可一键接受本片全部差异。

## 比较规则

- 忽略标点差异；忽略常见繁简/异体字归一（仅用于比较，原文始终不改写）。
- 句匹配相似度阈值可调；短句自动提高阈值以防虚词误配。
- 规则变化即触发重新对齐；**人工锁定的组原样保留**，自动结果与人工成果互不覆盖。

## 技术栈

- Vue 3 + Vite + TypeScript + Arco Design Vue
- 两级序列对齐（段落级 + 段内句级 Needleman-Wunsch），字符级 LCS diff
- 无后端，全部计算与存储在浏览器本地

## 本地开发

```bash
npm install
npm run dev      # 开发服务器
npm test         # 单元/集成测试（对齐算法、校记迁移、导出、组件冒烟）
npm run build    # 类型检查 + 生产构建到 dist/
npm run preview  # 预览生产构建
```

## Docker

```bash
docker build -t sologsb-1023 .
docker run --rm -p 10023:80 sologsb-1023
```

## 数据说明

版本正文、对齐结果、人工锁定、校记、来源、撤销记录均保存在当前浏览器。清除站点数据会删除草稿，请定期导出 JSON 或对照 HTML 备份。
