# 校异斋 · 多版本文本自动比对与人工校勘工具

面向古籍整理的多版本校勘工作台：一次载入同一作品的 3–5 个版本并指定底本，自动按段落与句子对齐到同一组，组内逐版标出**改动 / 新增 / 删减 / 疑错位**；人工挪动只在同版列内进行，绝不串位，每版校记与来源锚定原句、重对齐不丢；支持多草稿、旧稿重开与清晰的对照导出。

## 核心功能

- **多版本同校（3–5 版）**：导入或粘贴多个版本，指定一个底本；底本固定首列，参校本逐列排开，可勾选参与对照的版本。
- **段 + 句两级自动对齐**：以底本段落为锚做 Needleman–Wunsch 段落对齐，再在配对段落内做句对齐；底本每句成组，参校本多出的句子自动成为「新增」组，底本有而他版无的句子标「删减」。
- **组内逐版标注**：每格自动判定 相同 / 改动 / 新增 / 删减 / 疑错位；改动格按字符级 LCS 逐字标出异文（他版新增字、底本删去字），并显示相似度。
- **人工修配不串位**：「配对上移/下移」只交换**同一版本列**内的句与组（交换后严格校验 `unit.versionId` 仍属该列）；「整组上移/下移」把组内各版整体挪动，校记来源始终绑定原句。
- **校记随原句走**：校勘说明与来源按「版本 + 原句内容哈希」锚定。换底本、增减版本、改规则、重新对齐后，只要原句还在，校记与人工判定就自动回到该句。
- **规则可调且不毁数据**：忽略标点、忽略常见繁简/异体字、疑错位阈值滑块；改规则只重算判定，不重建对齐、不改原文、不动校记。
- **长文本分片**：每 24 个段落让出一次主线程并回传进度，实测约 1.4 万个句段、3 个版本可在数秒内完成；表格用虚拟滚动，渲染不随全文膨胀。
- **多草稿**：多个校勘项目各自独立保存于 localStorage，可新建、打开、重命名、删除、备份；旧草稿 JSON 可随时导入重开。
- **撤销 / 重做**：对齐、改规则、挪动、改判、校记、版本增删、接受等操作均进入历史（内存中保留 50 步）。
- **接受与跳转**：勾选批量接受、一键接受全部、`Alt+↓` 跳转下一处未接受差异、`A` 接受勾选、`Ctrl/⌘+Z / Y` 撤销重做。
- **导出**：Markdown 全文对照（组组列出各版原文、判定、校记、来源）、Markdown 仅异文校记、JSON 完整数据（可再导入）。

## 技术栈

- Vue 3 + Vite + TypeScript
- Arco Design Vue 2
- 自研虚拟滚动对照表（支持动态行高、scroll-to-group）
- 浏览器 localStorage，无后端，全部计算本地执行

## 本地开发

```bash
npm install
npm run dev
```

## 生产构建

```bash
npm run build
npm run preview
```

## Docker

```bash
docker build -t sologsb-1023 .
docker run --rm -p 10023:80 sologsb-1023
```

容器内 nginx 监听 `80`，映射到宿主 `10023`。

## 数据说明

版本正文、对齐结果、校记、人工判定与多草稿索引都保存在当前浏览器的 localStorage（键名 `collation-drafts-v2`）。清除站点数据会删除草稿，建议定期使用「导出 / 草稿备份」保存 JSON。
